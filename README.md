# 傘レベル診断アプリ（Umbrella Checker）

東京23区の時系列天気予報を取得し、「日傘」と「雨傘」の必要度をそれぞれ5段階レベルとメッセージで分かりやすく提案するWebアプリ。

**公開 URL:** https://sakamoto-08.github.io/umbrella-checker/

## 主な機能

- **地域選択（東京23区）** … 全区をドロップダウンで選択
- **本日の時系列予報** … 現在時刻以降の天気・降水量・UVインデックスを表示
- **日傘レベル診断（5段階）** … UVインデックスから日焼け対策レベルを算出
- **雨傘レベル診断（5段階）** … 降水量と天気コードから雨傘の出番レベルを算出
- **分かりやすい提案メッセージ** … 「折りたたみ傘があると安心」「しっかり日差し対策！」などの直感的な文言表示

## 技術スタック

- HTML5
- CSS3（Flexbox / Grid）
- JavaScript（Vanilla JS）
- **Weather API**: Open-Meteo（完全無料・APIキー不要）
- **Icon Library**: Font Awesome（Webフォントアイコン）
- Git / GitHub / GitHub Pages

## 設計のポイント

1. **降水確率との混同を防ぐ5段階評価**
   パーセンテージ表示によるユーザーの混乱を防ぐため、日傘・雨傘ともに5段階レベル（★）＋アドバイスメッセージの形式で表示。
2. **外部API連携と非同期処理**
   `fetch` および `async/await` を用いたデータ取得処理と、読み込み中・エラー時の表示を実装。
