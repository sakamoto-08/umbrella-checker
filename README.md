# 傘レベル診断アプリ（Umbrella Checker）

東京23区の時系列天気予報を取得し、「日傘」と「雨傘」の必要度をそれぞれ5段階レベルとメッセージで分かりやすく提案するWebアプリ。

**公開 URL:** (GitHub Pagesにデプロイ後設定)

## 主な機能

- **地域選択（東京23区）** … 23区内の主要エリアをドロップダウンで選択
- **本日の時系列予報** … 3時間ごとの天気・気温・降水量・UVインデックス（紫外線強度）を表示
- **日傘レベル診断（5段階）** … UVインデックスと天候データから日焼け・熱中症対策レベルを算出
- **雨傘レベル診断（5段階）** … 降水量と降水確率から雨傘の出番レベルを算出
- **分かりやすい提案メッセージ** … 「折りたたみ傘があると安心」「しっかり日差し対策！」などの直感的な文言表示

## 設計のポイント

1. **降水確率との混同を防ぐ5段階評価**
   パーセンテージ表示によるユーザーの混乱を防ぐため、日傘・雨傘ともに5段階レベル（★やアイコン点灯）＋アドバイスメッセージの形式で表示。
2. **外部API連携と非同期処理**
   `fetch` および `async/await` を用いた堅牢なデータ取得処理、および読み込み中（LoadingUI）・エラー時の例外ハンドリングを実装。
